Personal project · Oct 2026 to present

Homelab

A self-hosted network that I built and keep running at home. A Proxmox VE host runs services in LXC containers. Beside it, a Raspberry Pi 5 runs Docker Compose and carries the parts everything else depends on: DNS for the whole network, a reverse proxy, remote access and monitoring.

DNS
Pi-hole v6 filters DNS for every device. Split-horizon DNS makes the internal wildcard domain resolve only on the LAN or the VPN, so it stays hidden from the public internet.
HTTPS
Nginx Proxy Manager sits in front of every internal service with a Let's Encrypt wildcard certificate, issued by DNS-01 challenge through the Cloudflare API with a least-privilege token. Every service gets HTTPS and no inbound port is open.
Remote access
A Tailscale subnet router, with no port forwarding. The DNS is designed so remote access keeps working even if Pi-hole goes down.
Monitoring
Uptime Kuma with DNS-level health checks rather than HTTP only, with alerts sent to Discord through a webhook.
Hardening
Pinned image versions and memory limits on containers.
Troubleshooting
Worked through outbound SMTP and DNS connectivity problems with dig, nc and openssl s_client, and recovered broken Linux package states.
Documentation
One place for the IP plan (separate ranges for infrastructure and services, static assignments, a defined boot order), the DNS rules and the runbooks.

Trace a request

A small model of how the lab answers a request, running in your browser. The domain and addresses are examples, since the real ones stay private. Public names are looked up for real over DNS-over-HTTPS.
